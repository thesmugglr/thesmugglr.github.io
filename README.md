# IIITD Black Market (built site)

This repository only holds the compiled static site served by GitHub Pages. It is generated by `npm run deploy:pages` from the private source repository; do not edit it by hand.

The workflow in `.github/workflows/keepalive.yml` pings the backend twice a week so a free-tier Supabase project is not paused for inactivity. When the repository has been quiet for 30 days it also adds an empty commit, because GitHub switches off scheduled workflows in a public repository after 60 days without one.
